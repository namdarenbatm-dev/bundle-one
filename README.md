# باندلینگ ورژن ۶ — توسن تکنو

PWA پایه با رابط فارسی RTL، لوگوی توسن تکنو و فونت Yekan برای ادامه توسعه در GitHub.

## اجرا
```bash
npm install
npm run dev
```
## ساخت نسخه انتشار
```bash
npm run build
npm run preview
```

## امکانات حاضر
- دو بخش کارگزار: «بسته‌های پیشنهادی مدیریت» و «پیشنهاد اقتصادی هوشمند»
- دریافت بودجه خرید و نمایش بسته‌های قابل خرید
- نمایش مبلغ دقیق کسری برای بسته‌هایی که با افزایش بودجه قابل خرید می‌شوند
- مرتب‌سازی بر اساس کمترین قیمت هر کارتخوان
- خروجی CSV و چاپ / ذخیره PDF از مرورگر
- PWA پایه با manifest و service worker
- بخش تنظیمات نمونه مدیریت
- لوگوی ارائه‌شده و فونت Yekan داخل پروژه

## توجه پیش از انتشار
این پروژه اسکلت اجرایی اولیه است. مقادیر مالی داخل تنظیمات نمونه هستند و موتور تولید ترکیب‌ها باید قبل از استفاده عملیاتی با قواعد کامل کسب‌وکار و آزمون‌های مالی تأیید شود. اعداد نمونه: قیمت پایه کارتخوان ۱۹، بازاریابی ۰، کف رقابتی ۱۵، بهای تمام‌شده کش‌لس ۲۵، قیمت فروش کش‌لس ۴۲ و سود کش‌لس ۲ (همه میلیون تومان).

قواعد مصوب: بودجه کارگزار فقط ظرفیت خرید است و منبع تأمین تخفیف نیست؛ بودجه بازاریابی در قیمت پیش از باندل لحاظ می‌شود و از بودجه تأمین‌شده توسط کش‌لس کسر نمی‌شود. بسته‌ای که کف قیمت رقابتی را نقض کند یا بودجه باندل منفی داشته باشد نباید نمایش داده شود.

## انتشار روی GitHub Pages (v6.1)
1. فایل‌های این پروژه را در ریشه مخزن بگذارید (شاخه `main`).
2. در GitHub: **Settings → Pages → Build and deployment → Source = GitHub Actions**.
3. با هر push روی `main`، workflow در `.github/workflows/deploy.yml` پروژه را Build و منتشر می‌کند.
4. آدرس نهایی مثل `https://USER.github.io/REPO/` است. **خود پوشه‌ی سورس (بدون Build) را منتشر نکنید**؛ فقط خروجی `dist` باید سرو شود، وگرنه صفحه سفید/خطای بارگذاری می‌بینید.

مسیرها نسبی هستند (`base: './'`)؛ فونت یکان در `src/assets/Yekan.ttf` و لوگو/آیکون‌ها در `public/assets/` قرار دارند.
